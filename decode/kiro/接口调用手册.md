# kiro-cli 3.5.0 接口调用手册

> 目标：每个接口都能照着 curl 直接敲。所有参数名、header 名都来自二进制解包结果；标 ⚠️ 的是推断字段（名字确定、可选性不确定），先用不带该字段的请求试。

---

> **先确认账号类型**：AWS Builder ID / 社交账号（Google·GitHub）/ 企业账号（Identity Center）走三套不同的认证协议，`tokentype` 头与调用序列都不同。详见 `账号类型对照.md`，下面第 0、9 节只覆盖通用部分。

## 0. 先解决 Token

所有业务接口都要 `Authorization: Bearer <access_token>`。token 落地在系统钥匙串，服务名 `kiro-cli`，账号形如 `kirocli:auth:*`。

```bash
# macOS
security find-generic-password -s kiro-cli -w | python3 -m json.tool

# Linux（有 libsecret / gnome-keyring 时）
secret-tool search service kiro-cli

# 容器/无钥匙串：自己跑一次登录，抓 3128 端口的回调，再从 /oauth/token 的响应里取 accessToken
export KIRO_TOKEN='...'
```

区域决定端点，先确认你的 profile ARN 里的 region（`arn:aws:codewhisperer:us-east-1:...`）：

```bash
export KIRO_REGION=us-east-1
export KIRO_BASE="https://q.${KIRO_REGION}.amazonaws.com"            # 推理 + 账号
export KIRO_CTRL="https://management.${KIRO_REGION}.kiro.dev"        # 控制面
```

## 1. 公共 Header 逐项说明

| Header | 必填 | 值 | 作用 |
|---|---|---|---|
| `content-type` | ✅ | `application/x-amz-json-1.0` | Smithy awsJson1_0 序列化格式。**写错直接 415/400** |
| `x-amz-target` | ✅ | `<Service>.<Operation>` | 唯一的“路由”手段。所有接口路径都是 `/`，靠这个 header 选接口 |
| `authorization` | ✅ | `Bearer <token>` | OAuth access token（`httpBearerAuth` 方案） |
| `amz-sdk-invocation-id` | 建议 | 任意 UUID v4 | 幂等/追踪 ID，服务端日志里有，报错时方便对账 |
| `amz-sdk-request` | 建议 | `attempt=1; max=3` | 客户端声明的重试预算，缺省也能通 |
| `x-amzn-trace-id` | 可选 | `Root=1-xxxx` | 链路追踪，不填服务端会自己生成 |
| `x-amzn-kiro-agent-mode` | 可选 | `agent` ⚠️ | 只在 `GenerateAssistantResponse` 上用，开启 agent 模式（工具调用/多步） |
| `x-amzn-kiro-profile-arn` | 可选 | `arn:aws:codewhisperer:...` | 多 profile 时指定身份；也可放 body 的 `profileArn` |
| `x-amzn-kiro-attempt` / `x-amzn-kiro-fallback` | 内部 | `1` / `true` | CLI 自己重试与模型回退的标记，正常调用**不用带** |
| `x-amzn-codewhisperer-optout` | 可选 | `true` | 遥测 opt-out |
| `accept` | 流式必填 | `application/vnd.amazon.eventstream` | 只有 `GenerateAssistantResponse` 需要；不写可能拿不到流 |
| `user-agent` | 可选 | `aws-sdk-rust/1.6.0 ua/2.1 api/codewhispererruntime/0.1.19636 os/linux lang/rust/1.94.1 md/appVersion-3.5.0 app/AmazonQ-For-CLI` | 标准 UA。`md/appVersion-3.5.0` 段带版本号 |
| `x-amz-user-agent` | 可选 | `aws-sdk-rust/1.6.0 ua/2.1 api/codewhispererruntime/0.1.19636 os/linux lang/rust/1.94.1 m/F app/AmazonQ-For-CLI` | SDK 业务指标 UA。**注意是 `m/F`，不是 `md/appVersion-...`**，两个 header 值不一样 |
| `tokentype` | 实测发送 | `API_KEY` / `BUILDER_ID` / `SOCIAL` | 凭证类型标识；API Key 模式下必带 |
| `x-amzn-codewhisperer-optout` | 实测发送 | `false`（默认） | 遥测退出标记，每条请求都带 |

### 1.1 关于“版本号”：没有独立的版本 header

全量扫过 header 名，**不存在** `x-amzn-kiro-version` / `x-kiro-version` 这类字段。版本走的是这三个地方：

| 载体 | 实际值 | 证据 |
|---|---|---|
| `user-agent` | `aws-sdk-rust/1.6.0 ua/2.1 api/codewhispererruntime/0.1.19636 os/linux lang/rust/1.94.1 md/appVersion-3.5.0 app/AmazonQ-For-CLI` | **实测抓包**（mock 端点记录） |
| `x-amz-user-agent` | 同上去掉 `md/appVersion-3.5.0`，换成 `m/F` | **实测抓包**，与 `user-agent` 值不同 |
| KAS/agent 路径的另一套 UA 模板 | `KiroCLI/3.5.0 KAS/<kas版本> os/linux md/appVersion-3.5.0 app/AmazonQ-For-CLI` | 二进制 `0x43dd0a` 格式串；`aws_common/user_agent_override_interceptor.rs`（env `AWS_TOOLING_USER_AGENT`、`KIRO_CLI_CLIENT_APPLICATION`）。**这条没在 API 抓包里出现**，属 KAS/agent 通道，使用位置为推断 |
| 请求体字段 | `clientVersion`（控制面 `GetEffectiveEnterpriseManagementResourceWithToken`、`GetUserPreference`）、`client_version`（ACP `initialize`） | 字段簇 |
| MCP OAuth 客户端标识 | `kiro-cli/3.5.0` | `agent/src/agent/mcp/oauth_util.rs` 附近的字面量 |

拆解 UA 各段：

- `KiroCLI/3.5.0` — 客户端名 + 版本
- `KAS/<版本>` — 内置 Kiro Agent Server 的版本（本机 `kiro-cli diagnostic` 里 `extracted-kas-versions = []`，未下载时为空）
- `os/linux` — 平台
- `md/appVersion-3.5.0 app/AmazonQ-For-CLI` — AWS SDK 业务指标段（`md/` = metadata，`app/` = 应用名）

自测时**完全可以不带 UA**，服务端不按它鉴权；要带就贴上面这串真实的，别用我上一版写的占位值。

## 2. `GetUsageLimits` — 用量额度（最适合第一个试的接口）

**用途**：查 token/请求数剩余额度、订阅信息。无副作用。

```bash
curl -sS -X POST "$KIRO_BASE/" \
  -H "content-type: application/x-amz-json-1.0" \
  -H "x-amz-target: AmazonCodeWhispererService.GetUsageLimits" \
  -H "authorization: Bearer $KIRO_TOKEN" \
  -H "amz-sdk-invocation-id: $(python3 -c 'import uuid;print(uuid.uuid4())')" \
  -H "amz-sdk-request: attempt=1; max=3" \
  -d '{"origin":"CLI"}' | python3 -m json.tool
```

参数：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `origin` | string | 建议 | 调用来源，枚举见附录 A，CLI 用 `CLI` |
| `profileArn` | string | 否 ⚠️ | 指定 profile；企业多 profile 时需要 |
| `resourceType` | string | 否 ⚠️ | 资源维度过滤 |
| `isEmailRequired` | bool | 否 ⚠️ | 返回里是否带邮箱 |
| `nextToken` | string | 否 | 分页游标 |

返回示例：

```json
{
  "limits": [...],
  "usageBreakdownList": [
    { "type": "AGENTIC_REQUEST", "currentUsage": 12, "usageLimit": 500, "percentUsed": 2.4 }
  ],
  "subscriptionInfo": {
    "subscriptionTitle": "Kiro Pro",
    "overageCapability": "ENABLED",
    "upgradeCapability": "AVAILABLE",
    "subscriptionManagementTarget": "https://app.kiro.dev/account/usage"
  },
  "userInfo": { "email": "...", "userId": "..." },
  "totalUsage": 12
}
```

## 6. `GenerateAssistantResponse` — 主对话接口（流式）

```bash
curl -sS -N -X POST "$KIRO_BASE/" \
  -H "content-type: application/x-amz-json-1.0" \
  -H "accept: application/vnd.amazon.eventstream" \
  -H "x-amz-target: AmazonCodeWhispererStreamingService.GenerateAssistantResponse" \
  -H "authorization: Bearer $KIRO_TOKEN" \
  -H "amz-sdk-invocation-id: $(python3 -c 'import uuid;print(uuid.uuid4())')" \
  -H "amz-sdk-request: attempt=1; max=3" \
  -H "x-amzn-kiro-agent-mode: agent" \
  --output body.bin \
  -d '{
    "conversationState": {
      "conversationId": "11111111-1111-1111-1111-111111111111",
      "chatTriggerType": "MANUAL",
      "currentMessage": {
        "userInputMessage": {
          "content": "用一句话解释什么是 RAII",
          "modelId": "claude-sonnet-4",
          "origin": "CLI",
          "userInputMessageContext": {
            "envState": { "operatingSystem": "linux", "currentWorkingDirectory": "/tmp" },
            "tools": [],
            "toolResults": []
          }
        }
      }
    }
  }'

python3 decode_eventstream.py body.bin
```

### 6.1 顶层参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conversationState` | object | ✅ | 会话容器，见下表 |
| `profileArn` | string | 否 | 身份 profile |
| `modelId` | string | 否 | 顶层也可指定模型（一般放 `currentMessage` 里） |
| `additionalModelRequestFields` | object | 否 | 透传模型参数：`{"systemPrompt": "..."}`、thinking 配置等 |
| `clientCacheConfig` | object | 否 | `{"useClientCachingOnly": true}` 提示缓存策略 |

### 6.2 `conversationState`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conversationId` | string(uuid) | ✅ | 会话 ID，同一轮多轮对话复用 |
| `chatTriggerType` | enum | ✅ | `MANUAL`（用户输入）/ `DIAGNOSTIC`（诊断）/ `INLINE_CHAT`（行内） |
| `currentMessage` | object | ✅ | 见 6.3 |
| `history` | array | 否 | 历史轮次，元素为 `{userInputMessage}` 或 `{assistantResponseMessage}` |
| `workspaceId` | string | 否 | 工作区 ID |
| `agentContinuationId` | string | 否 | agent 续跑令牌（`x-amzn-kiro-agent-mode` 场景） |
| `agentTaskType` | string | 否 | agent 任务类型 |
| `rootConversationId` | string | 否 | 子会话指回主会话 |

### 6.3 `currentMessage.userInputMessage`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `content` | string | ✅ | 用户文本 |
| `modelId` | string | ✅ | 模型 ID，从接口 9 的 `ListAvailableModels` 拿 |
| `origin` | enum | ✅ | 见附录 A，CLI 用 `CLI` |
| `userInputMessageContext` | object | 建议 | 见 6.4 |
| `images` | array | 否 | `[{format:"png"\|"jpeg"\|"gif"\|"webp", source:{bytes:base64}}]` |
| `documents` | array | 否 | md/txt/pdf/csv/doc/xls 文档块 |
| `cachePoint` | object | 否 | prompt cache 打点，长上下文省钱用 |
| `userIntent` | string | 否 | 意图标注 |

### 6.4 `userInputMessageContext`

| 字段 | 类型 | 说明 |
|---|---|---|
| `editorState` | object | `{cursorState, relevantDocuments[], useRelevantDocuments, workspaceFolders[]}` |
| `shellState` | object | `{shellName, shellHistory:[{command,directory,exitCode,stdout,stderr}]}` |
| `gitState` | object | 仓库/分支状态 |
| `envState` | object | `{operatingSystem, currentWorkingDirectory, environmentVariables:[{key,value}]}` |
| `appStudioContext` | object | `{namespace, propertyName, propertyValue}` |
| `diagnostic` | object | LSP 诊断 `{uri, range:{start,end}, ...}` |
| `consoleState` | object | 控制台上下文（region / serviceId / componentsTree / userSelection） |
| `userSettings` | object | `{hasConsentedToCrossRegionCalls}` |
| `additionalContext` | array | `[{type, innerContext:{key,value}}]` |
| `toolResults` | array | `[{toolUseId, content:[{text}], status:"success"\|"error"}]` |
| `tools` | array | `[{toolSpecification:{name, description, inputSchema:{json:{...}}}}]` |

### 6.5 响应：事件流

二进制帧，必须解码（用 `/workspace/work/kiro-api-re/decode_eventstream.py`）。帧头 `:event-type` 取值：

| event-type | payload 关键字段 |
|---|---|
| `assistantResponseEvent` | `content`（增量文本） |
| `toolUseEvent` | `name`、`toolUseId`、`input`（工具调用） |
| `citationEvent` | `citationLink` |
| `codeReferenceEvent` | 代码引用 |
| `supplementaryWebLinksEvent` | `url`、`title`、`snippet` |
| `messageMetadataEvent` | `messageId`、`conversationId`、`utteranceId` |
| `contextUsageEvent` | `contextUsagePercentage` |
| `tokenUsageEvent` / `meteringEvent` | `uncachedInputTokens`、`outputTokens`、`totalTokens`、`cacheReadInputTokens`、`cacheWriteInputTokens` |
| `followupPromptEvent` | 后续建议 |
| `invalidStateEvent` | `reason`、`message`（出错） |
| 异常帧 | `:exception-type`：`ValidationException` / `ThrottlingException` / `AccessDeniedException` / `InternalServerException` |

## 7. `InvokeMCP` — 服务端 MCP 代理

```bash
curl -sS -X POST "$KIRO_BASE/" \
  -H "content-type: application/x-amz-json-1.0" \
  -H "x-amz-target: AmazonCodeWhispererStreamingService.InvokeMCP" \
  -H "authorization: Bearer $KIRO_TOKEN" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/list",
    "params": {}
  }'
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `jsonrpc` | string | ✅ | 固定 `"2.0"` |
| `id` | number/string | ✅ | 请求 ID，响应原样带回 |
| `method` | string | ✅ | `initialize` / `notifications/initialized` / `tools/list` / `tools/call` |
| `params` | object | 否 | `tools/call` 时是 `{name, arguments}` |
| `profileArn` | string | 否 | 身份 profile |

返回：`{"jsonrpc":"2.0","id":1,"result":{...}}`，错误走 `JsonRpcError`。

## 9. 认证接口

### 9.1 设备码流（无浏览器环境）

```bash
# 1) 申请
curl -sS -X POST "https://prod.us-east-1.auth.desktop.kiro.dev/oauth/device/authorization" \
  -H "content-type: application/json" \
  -d '{"client_id":"kiro-cli","scope":"openid profile email offline_access"}'
# → {"deviceCode":"...","verificationUri":"https://app.kiro.dev/...","expiresInMilliseconds":600000,"intervalInMilliseconds":5000}

# 2) 轮询（按 interval 循环，直到拿到 accessToken）
curl -sS -X POST "https://prod.us-east-1.auth.desktop.kiro.dev/oauth/device/poll" \
  -H "content-type: application/json" \
  -d '{"device_code":"..."}'
```

| 字段 | 说明 |
|---|---|
| `deviceCode` | 轮询凭证 |
| `verificationUri` / `verificationUriComplete` | 让人去这个页面点同意 |
| `expiresInMilliseconds` | 过期时间 |
| `intervalInMilliseconds` | 轮询最小间隔 |

### 9.2 浏览器门户（默认）

1. CLI 在本地起 `http://localhost:3128/oauth/callback`；
2. 打开 `https://app.kiro.dev/signin?state=<随机 state>`；
3. 同意后回调带 `code`；
4. `POST https://prod.us-east-1.auth.desktop.kiro.dev/oauth/token`（`grant_type=authorization_code`、`code`、`code_verifier`，PKCE S256）；
5. 刷新用 `grant_type=refresh_token`。

### 9.3 Builder ID（AWS SSO-OIDC）

```bash
# 先注册客户端（只需一次）
curl -sS -X POST "https://oidc.us-east-1.amazonaws.com/client/register" \
  -H "content-type: application/json" \
  -d '{"clientName":"kiro-cli","clientType":"public","scopes":["codewhisperer:completions","codewhisperer:analysis"]}'
# 再设备授权
```

## 13. 错误速查

| HTTP | `x-amzn-errortype` | 含义 / 处理 |
|---|---|---|
| 400 | `ValidationException` | body 字段名或类型错，先对比本手册字段 |
| 401 | `AccessDeniedException` / `UnauthorizedException` | token 过期或不是该服务签发 |
| 403 | `FeatureNotSupported` / `UnauthorizedCustomizationResourceAccess` | 权限/区域不对 |
| 429 | `ThrottlingException` / `TooManyRequestsException` | 退避重试（`amz-sdk-request` 的 attempt+1） |
| 500/503 | `InternalServerException` / `ServiceUnavailableException` | 重试；持续则换区域 |

响应头 `x-amzn-RequestId` 一定要留，报障用。

真实 header（逐字节）：

```
authorization: Bearer <api_key 或 access_token>
content-type: application/x-amz-json-1.0
x-amz-target: AmazonCodeWhispererService.GetProfile
amz-sdk-request: attempt=1; max=3

```

控制面 UA 只换 `api/` 段：`api/kirocontrolplanebearer/0.1.0`。

上表是 `user-agent`；**`x-amz-user-agent` 同时也会发**，值不同：

```
user-agent:      aws-sdk-rust/1.6.0 ua/2.1 api/codewhispererruntime/0.1.19636 os/linux lang/rust/1.94.1 md/appVersion-3.5.0 app/AmazonQ-For-CLI
x-amz-user-agent: aws-sdk-rust/1.6.0 ua/2.1 api/codewhispererruntime/0.1.19636 os/linux lang/rust/1.94.1 m/F app/AmazonQ-For-CLI
```

### 实测每次请求都会带的 header 全量

| Header | 实测值 |
|---|---|
| `host` | 目标端点 |
| `authorization` | `Bearer <token 或 api key>` |
| `content-type` | `application/x-amz-json-1.0` |
| `content-length` | 实际长度 |
| `x-amz-target` | 见各接口 |
| `x-amz-user-agent` | `... m/F app/AmazonQ-For-CLI` |
| `user-agent` | `... md/appVersion-3.5.0 app/AmazonQ-For-CLI` |
| `tokentype` | `API_KEY`（API Key 模式） |
| `x-amzn-codewhisperer-optout` | `false` |
| `amz-sdk-invocation-id` | uuid v4，每条不同 |
| `amz-sdk-request` | `attempt=1; max=3` |
| `accept` | `*/*` |
| `accept-encoding` | `gzip` |

UA 各段含义：

| 段 | 含义 |
|---|---|
| `aws-sdk-rust/1.6.0` | SDK 版本 |
| `ua/2.1` | UA 格式版本 2.1 |
| `api/codewhispererruntime/0.1.19636` | 服务名 + API 版本（控制面为 `api/kirocontrolplanebearer/0.1.0`） |
| `os/linux` `lang/rust/1.94.1` | 平台 / 语言 |
| `md/appVersion-3.5.0` | 业务指标段，**应用版本在这里** |
| `m/F` | 业务指标特性位（仅出现在 `x-amz-user-agent`） |
| `app/AmazonQ-For-CLI` | 应用名（沿用 Q CLI 壳） |

| 设置项 | 格式 | 填错的表现 |

| `api.krs.service` | JSON `{"endpoint":"...","region":"..."}` | `expected struct EndpointOverride`，覆盖被忽略 |
